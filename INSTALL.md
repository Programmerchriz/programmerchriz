# Install Chris UI Design

**Last updated:** September 25, 2026

## Give it to an agent

Download `chris-ui-design.zip` and attach it to a coding agent that supports reusable skills, or copy the contents of `AGENT_INSTALL.txt`.

The agent should install the complete `chris-ui-design/` folder and preserve its `references/` directory.

## Manual installation

1. Download and extract `chris-ui-design.zip`.
2. Move the complete `chris-ui-design/` folder into the skills directory supported by your coding environment.
3. Keep `SKILL.md` at the folder root.
4. Keep all files in `references/`; `SKILL.md` links to them by relative path.
5. Reload/restart the skill registry if the environment requires it.
6. Confirm the skill name `chris-ui-design` is discoverable.

If the agent uses a different skill mechanism, adapt only the installation/registration location. Do not rewrite the skill during installation.
