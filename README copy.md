# Chris UI Design

A portable coding-agent skill that encodes Chris's recurring UI/design language learned across product work and repeated design reviews.

**Skill name:** `chris-ui-design`  
**Last updated:** September 25, 2026

## What it captures

The package focuses on the design choices Chris repeatedly enforces:
- editorial/architectural composition;
- product-first hierarchy;
- neutral premium surfaces;
- real product imagery;
- information density without crowding;
- strong mobile behavior;
- restrained interaction/motion;
- factual human copy;
- inspiration without copying;
- explicit anti-AI-slop rules;
- browser-based visual QA.

It is intentionally not a universal design system. It is a reusable taste-and-decision layer for agents working in Chris's style.
