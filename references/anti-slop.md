# Anti-Slop Rules

Remove these unless there is a specific product reason.

## Visual anti-patterns

Avoid:
- generic AI purple;
- purple/blue glow backgrounds;
- automatic gradients;
- glassmorphism everywhere;
- huge soft shadows;
- giant rounded cards;
- nested cards inside cards;
- excessive pills;
- decorative blobs;
- random sparkles;
- generic folder/robot/brain AI icons;
- emoji standing in for real product icons;
- fake depth for its own sake;
- childish startup illustrations;
- ornamental hero art unrelated to product behavior.

## Content anti-patterns

Avoid:
- "AI-powered" as the main value;
- vague verbs such as unlock, supercharge, revolutionize;
- invented analytics;
- invented customer names;
- fake logos;
- fake testimonials;
- filler categories;
- lorem ipsum;
- copy that sounds impressive when read aloud but says nothing.

## Layout anti-patterns

Avoid:
- a card for every section;
- more than one obvious hero message;
- controls covering text/media;
- duplicated navigation;
- crowded text blocks with no scale contrast;
- oversized empty hero sections;
- tiny dashboard interfaces floating in large whitespace;
- mobile views that are simply desktop squeezed down.

## Reference anti-patterns

Do not:
- steal another site's copy;
- copy its exact UI;
- keep the same placement and only change colors;
- import a reference component without adapting it to product context.

The reference should change the quality of thinking, not erase authorship.

## Engineering anti-patterns

Avoid:
- many patch CSS files;
- broad selectors that affect unrelated screens;
- `!important` as normal architecture;
- duplicated markup for responsive variants;
- unnecessary JS for CSS behavior;
- magic coordinate positioning;
- UI that only works with one exact text length;
- shipping without browser QA.
